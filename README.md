# Bioimage Analysis Curriculum

This repository contains materials and structured metadata to design a modular, dependency-aware bioimage analysis (BIA) curriculum.

## Structure

- `curriculum/subjects/` — subject definitions
- `curriculum/topics/` — topic definitions
- `curriculum/paths/` — audience-specific learning paths
- `curriculum/graphs/` — dependency graph files
- `references/` — bibliography and source mappings
- `templates/` — templates for creating new entries

See `AGENTS.md` for project conventions, topic annotation schema, and workflow guidance.
